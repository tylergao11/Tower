# 主公快跑 · 新野

手机横屏微信 H5 单关游戏，使用 Phaser、TypeScript 和 Vite。

- 玩法策划：`游戏策划案.md`。
- 运行数值、卡牌与波次：`src/config.ts`。
- 战斗逻辑：`src/game/Battle.ts`。
- 美术清单、分层与序列动画：`assets/game/asset-manifest.json`。
- 资源加载与进度条：`src/loading.ts`。
- 开场：`src/render/Opening.ts`；战场对位：`src/render/layout.ts`。

开发入口为 `npm run dev`，端口为 5188。构建命令为 `npm run build`，输出目录为 `dist`；只打包当前资源清单引用的正式素材。

大帐“接着奏乐，接着舞”作为加载页：优先加载营帐、刘备与舞女，舞蹈播放期间下载战场资源。底部进度条按图片与音乐实际下载进度更新，完成画面准备后显示 100% 和居中的大号“进入布防”按钮；等待玩家点击进入，不再定时跳过。加载失败时保留重试入口。

手机操作：划动战场移动镜头，左右划动底部卡栏，上下划动选卡列表。点卡后点合法地面可以部署，也可以长按卡牌拖放；长按场上守军再拖动调整本层驻守点。普通划动经过守军或钱袋只移动镜头，不部署、不收钱。钱袋需要单独点击收取。

战斗镜头保持 1.2 倍。进入战场及重试时先给刘备镜头，停留 2 秒，再用 0.55 秒移到左下角出兵口；这段镜头不消耗布防倒计时。主动触摸战场或选卡立即交还镜头控制。划动战场可上下左右查看，镜头不会越出战场；拖着卡牌或守军靠近视野边缘时，镜头会随之移动。顶部按钮和底部卡栏保持固定。

界面按参考图重绘为笔刷标题、纸木底牌、深色薄框卡栏、铜钱军饷及护驾图章。主标题“主公快跑”，副标题“新野”。名称、价格、冷却、波次、提示和结算数字保留正式排版，不再使用纯图标代替全部文字。顶部没有跑酷进度条，速度仍按本作固定正常速度。

我方为蜀军：主帐标“刘”，营旗标“蜀”；按用户最终选择使用红旗、红色营帐。新战场为 `assets/game/shu-camp-integrated.webp` 一张整图，保留营帐、城内、城外及两侧楼梯的构图，以《主公快跑》参考图重绘笔触、描边和暮色光影。运行时只叠加单位、活动入口、翻板洞口和界面，不再拼接静态地板与背景。UI 源件及生成记录在 `art/source/ui-redraw/` 和 `art/ui-redraw-generation.json`，裁切命令为 `node tools/pack-ui-redraw.mjs`。

本轮非人物重绘素材已接入源码及资源映射。手机资源按原始 PNG 单次压缩为 WebP：战场保持 1672×941，品质 84；机关与特效按显示尺寸合入两张最长边不超过 1024 的图集，保留透明通道和 2 像素防串色边缘；UI 品质 86，小图标缩至所需尺寸。新图、活动件和交接说明在 `art/source/noncharacter-redraw/`。

正式地图、图集、人物和 UI 分别放在 `assets/game/`、`assets/game/atlases/`、`assets/game/characters/` 和两个 UI 子目录。原始图保留在 `art/source/`；无损裁切与旧素材加工中间文件放在 `art/packed/`，不进网页发布包。`npm run art:build` 从原图重建全部正式资源并清理已替换文件；`npm run art:clean` 仅清理已确认弃用且没有正式引用的文件。处理记录位于 `art/reports/`。按用户要求，本轮不启动浏览器、不做手机验收。

14 个角色使用完整身体关键帧，在 `tools/whole-character-art.mjs` 统一编排。人物原图放在 `art/source/characters/<角色编号>/poses.png`，生成记录及压缩设置在 `art/character-frames.json`，手机运行图集在 `assets/game/characters/`。游戏、卡牌和预览共用 `art/runtime/art-player.js`。

美术预览：`npm run art:preview`，打开 `http://127.0.0.1:8766/`。修改动作或人物原图后运行 `npm run art:configure`；全量资源重建运行 `npm run art:build`。人物一帧一张整身图，盾兵失盾时切换完整无盾姿势，不再拼接左右手。普通角色每帧 192 像素，三位英雄和舞女 256 像素，刘备 320 像素；WebP 品质 82，保留透明通道。

扛人和攀梁只保留整身图的对位点。旧人物拆件、关节配置、旧图集和临时重复图已从项目清除；旧制作文件送入 Windows 回收站，清理结果在 `art/review/character-cleanup.json`，待清理项为零。原始 PNG、参考图、压缩缓存和检查图不进入网页发布包。人物检查命令为 `npm run art:check-characters`，包含透明通道、动作、失盾变体及扛人对位。

关羽、张飞、诸葛亮已加入本关卡牌，并解除预备标记，进入战场前会加载三位武将。选卡页首行显示武将；每次初次进入预选 6 张（三位武将、地刺、连弩车、军需账房），另选 2 张即可布防，通关记录保留。同一武将只能在场一名，技能自动发动。关羽横扫、张飞震慑、诸葛亮远攻与击退，各自播放完整技能动作。

近战接敌保留当前目标，攻击动作期间停止追赶和转向，离开接敌范围需超过缓冲距离才恢复追击。普通受击使用染色反馈，不再抢占攻击或行走动画；眩晕、坠落仍会中断动作。

字体使用本地优设标题黑，正文及按钮不再回退到细楷体。完整源字体保存在 `art/source/fonts/`；`tools/pack-font.py` 根据实际界面文字生成 28 KB 左右的 WOFF2 子集，修改文案后用安装了 fonttools、brotli 的 Python 执行该脚本。字体加载完成才开放进入战场。

BGM 原文件来自 `C:/Ai/zhugongkuaipao/assets/game/liu-run-bgm-v1.mp3`，放在 `assets/audio/`。`src/audio/GameMusic.ts` 按该项目 `music.js` 移植：原生 audio 循环，音量 0.65，点击/touchend 解锁，WeixinJSBridgeReady 恢复，暂停和切后台停止播放。音乐也参与加载完成门槛。

顶部信息条和战斗镜头分区，不盖住营帐；刘备驻守营帐左侧（第三层第七格），面对左边。武将与亲卫按站姿透明轮廓实测缩放，可见身高分别为 170 和 130 逻辑像素；`tools/measure-characters.mjs` 随美术配置/构建刷新数据，动画姿势共用固定比例。血条首次受伤后持续显示，治疗回满也保留。删除手动回营入口及其指令，救下后的波末自动回位保留；护驾不再叠加状态和次数文字。
